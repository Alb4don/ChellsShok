# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
This tool is intended for security testing purposes only. If you discover a vulnerability within the tool itself (e.g., it exposes the user to RCE):
1. Do not open a public GitHub issue.

## Ethical Use
This tool exploits CVE-2014-6271. It must only be used on systems you own or have explicit written permission to test. Unauthorized use is illegal.
